# Website Văn Phòng Phẩm 

## Giới Thiệu 

Trang web để trưng bày, giới thiệu và bán các sản phẩm như **giấy in**, **bút viết**, **sổ tay**, **file tài liệu và dụng cụ học tập** . *Giúp cho học sinh và phụ huynh dễ tiếp cận*

## Bảng Thư Mục

|Thư Mục|Nội Dung|
|:---:|:---:|
|data|Chứa dữ liệu đơn hàng trong các tháng|
|docs|Những đơn hàng cần nhâph thêm , dữ liệu nhập hàng|
|media|Chứa hình ảnh của web|

## Liệt Kê Nội Dung Dự Án Bằng Powershell

Lệnh chạy trên powershell để liệt kê nội dung dự án : 
```Shell
Get-ChildItem -Recurse
```
